# 앳홈 집앞 분리배출 (가칭) PWA

아파트 입주민이 문 앞에 내놓은 재활용품을, **같은 단지에 사는 도우미(이웃)**가 단지 분리수거장에 대신 배출해 주는 서비스의 모바일 웹앱입니다.
앳홈 카케어의 확장 서비스로, 같은 Supabase 프로젝트와 카카오 로그인을 함께 씁니다.

> 우리 일은 폐기물 처리가 아니라 **분리배출 대행**입니다. 손님 화면에는 "수거비·처리비" 대신 **"이용료"**라고만 씁니다.

## 지금 상태

- **미리보기 모드**로 돌아갑니다. (`supabase-integration.js` 의 `DB_READY = false`)
  예시 단지 3곳과 예시 일감이 휴대폰 안에만 저장되고, 서버에는 아무것도 보내지 않습니다.
  손님 → 도우미 → 관리자 흐름을 한 휴대폰에서 모두 눌러 볼 수 있습니다. (미리보기에서는 로그인하면 관리자 메뉴도 보입니다)
- DB를 적용한 뒤 `DB_READY = true` 로 바꾸면 실제 운영 모드가 됩니다. 그 뒤에도 주소 끝에 `?demo=1` 을 붙이면 미리보기로 볼 수 있습니다.
- **무료 시범 기간**: `prices.js` 의 `freePilot: true` 동안 손님 이용료는 0원입니다.

## 화면

| 주소 | 화면 |
| --- | --- |
| `#/` | 홈 · 단지 검색 (이용 가능 / 승인 대기 / 준비 중) |
| `#/c/단지id` | 단지 규칙 확인 + 신청 (승인된 단지만 신청 화면이 열림) |
| `#/my` | 내 신청 · 취소 · 완료 사진 보기 · 알림 켜기 |
| `#/helper` | 도우미 신청 → 승인 후 새 일감 / 맡은 일(완료 사진) / 정산 |
| `#/admin` | 관리자: 신청 · 도우미 승인 · 단지 규칙 · 정산 기록 |

## 파일 구성 (불러오는 순서)

| 파일 | 하는 일 |
| --- | --- |
| `core.css` | 화면 스타일 |
| `prices.js` | **요금 — 요금은 여기서만 고칩니다** (모두 예시, 시범 후 확정) |
| `supabase-integration.js` | DB 연동, 카카오 로그인, 사진 올리기, 알림 구독, 미리보기 모드 |
| `app.js` | 화면 이동과 각 화면 |
| `service-worker.js` | 오프라인 캐시, 푸시 알림 표시 |
| `database/` | Supabase SQL (순서대로) — `database/README.md` 참고 |
| `supabase/functions/pickup-notify` | 새 일감·완료 알림 보내는 함수 |

## 고칠 때 약속

- CSS·JS를 고치면 `index.html` 의 `?v=` 와 `service-worker.js` 의 `CACHE` 번호·`ASSETS` 의 `?v=` 를 같이 올립니다.
- 표 이름은 `pickup_` 으로 시작합니다. 새 SQL은 `database/` 에 다음 번호로 넣고 `database/README.md` 에 한 줄 적습니다.
- 코드에 넣어도 되는 키는 publishable(공개) 키뿐입니다. 비밀키는 Supabase 설정 화면에만 넣습니다.

운영 전에 할 일은 [`docs/SETUP.md`](docs/SETUP.md) 에 정리되어 있습니다.
