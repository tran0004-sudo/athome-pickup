# 데이터베이스 SQL (Supabase)

앳홈 카케어와 **같은 Supabase 프로젝트**를 씁니다. 이 저장소의 표는 모두 `pickup_` 으로 시작합니다.
파일 이름 맨 앞 두 자리가 **실행 순서**, 그다음 8자리가 만든 날짜입니다.
새로 SQL을 만들면 마지막 번호 다음 번호를 붙여 이 폴더에 넣고, 아래 표에 한 줄 추가합니다.

## 실행 방법

Supabase → **SQL Editor** 에 파일 내용을 붙여넣고 **한 번에** 실행합니다.
먼저 카케어 저장소의 `database/14번`(관리자 `is_owner()`)이 적용되어 있어야 합니다. 없으면 오류를 내고 전체가 취소됩니다.

## 실행 순서

| 순서 | 파일 | 하는 일 |
| --- | --- | --- |
| 01 | `01_20261124_pickup_core.sql` | 단지(배출 요일·시간·승인 상태), 도우미, 신청·배정·완료, 정산 지급, 푸시 구독 표 + RLS·GRANT + 화면용 함수 + 완료 사진 비공개 저장소 |

## 누가 무엇을 보나

| 자료 | 손님 | 도우미 | 관리자 |
| --- | --- | --- | --- |
| 단지 목록·규칙 | 누구나 | 누구나 | 전부 + 고치기 |
| 신청 (동·호수·연락처) | 자기 것만 | 맡기 전: 날짜·동·봉투만 / 맡은 뒤: 동·호수·메모 (연락처는 안 보임) | 전부 |
| 완료 사진 | 자기 신청 사진만 | 자기가 올린 것만 | 전부 |
| 도우미 정보 | — | 자기 것만 | 전부 |
| 정산 | — | 자기 것만 | 전부 |

## 나중에 추가할 표 (2차)

- 구독(월 4회), 손님 결제 기록 — 유료 전환 때. 유료 전환 전에는 서버에서 요금을 다시 계산하도록 `pickup_create_request` 를 바꿔야 합니다.
